# Working style

- Propose changes, don't apply them. For any file edit, show the diff or the new content in chat; I will make the edit myself.
- Don't run state-changing commands (file writes, `git commit`/`push`, installs, builds, etc.). Describe the command and I'll run it.
- Read-only investigation (grep, ls, cat, `git status`/`diff`/`log`, and similar) is fine to run directly — no need to ask first.
